# Mrs. Honey Avatar-Lab

Isolierte Testseite fuer die Mrs.-Honey-Animation.

- Start: `http://127.0.0.1:<port>/avatar-lab/` aus dem Paketordner heraus
- Nutzt vorhandene Assets unter `../assets/...`
- Aendert keine Dateien der Haupt-App
- Ueber `Tuning kopieren` lassen sich Werte gezielt fuer eine spaetere Uebernahme sammeln

Die Haupt-App laedt diesen Ordner nicht. Experimente in `avatar-lab/` bleiben deshalb vom normalen Spiel getrennt, bis einzelne Aenderungen bewusst in `app.js` oder `styles.css` uebernommen werden.
